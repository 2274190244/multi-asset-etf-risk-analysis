# 固定样本的标准化研究输入

这是从 Phase 1/3 原始归档提取的真实历史数值输入，不是合成数据，也不是预先写好的绩效结论。普通使用者运行根目录的 `scripts/build_research_demo.py`，即可调用既有 Phase 2–5 引擎重新计算页面证据。

| 文件 | 内容 |
|---|---|
| market_prices.csv | 2023-08-14 至 2026-08-12，共 726 个共同交易日、五只 ETF 的前复权市场价格；不是 NAV |
| tracking_levels.csv | 13 条 ETF / 指数 / 黄金基准序列，保留各自实际日期；ETF 序列采用原 Phase 3 的 NAV 与分红处理 |
| provenance.json | 8 组比较的来源 URL、官方身份/参考基准角色、价格口径、请求区间、已知采集时间、原始文件哈希、分红记录与限制 |
| sha256.json | 上述三个文件的 SHA-256；生成前必须校验 |

来源包括东方财富、华泰柏瑞/易方达等基金披露、中证指数、巨潮指数及上海黄金交易所，逐序列 URL 与口径以 `provenance.json` 为准。上市交易所/基金公告用于官方基准与分红证据；指数供应商与行情供应商提供历史数值。公开可访问并不代表没有使用条款，原提供方保留数据权利；本仓库不授予第三方数据的再分发或商业使用许可。

## 生成链与边界

维护者在持有完整本地归档时，可运行：

```console
python scripts/prepare_research_inputs.py --output-dir data/research_demo_candidate
```

此维护命令验证原 Phase 1 原始哈希、日期及保存价格，并复用原 Phase 3 解析器、分红核对和口径判断；提取后核对原 Tracking 汇总。目标目录必须不存在。候选输入需要重新审计后才能替换已发布快照，普通克隆不具备这些原始归档。

这里没有附带原始 HTTP 响应、PDF、SQLite 或完整采集审计包。因此可复现的是**标准化输入之后的研究数值和展示**，不是从原始网站采集到每条 NAV 的完整独立验证链。旧市场价格快照的采集时间不可恢复，明确记录为 `unknown_legacy_snapshot`，不能用此次打包时间冒充。各 NAV、指数和黄金数据的已知时间保留在来源记录中。

原结果的所有限制继续适用：前复权价格存在版本与分红口径局限，NAV 分红记录完整性有假设，三只股票 ETF 的全收益参考不替代官方价格指数，黄金/国债严格跟踪指标仍不可用。没有未来填充或人为补齐观测。重新从供应商获取同区间数据也可能因历史修订而产生不同数值。

`nav_data_quality` 保留原流程对候选 NAV 源的检查记录；其中 159915.SZ 的 Eastmoney 候选记录未用于最终 Tracking。最终实际来源以 `pairs` 为准，该 ETF 使用 E Fund（易方达）序列。
