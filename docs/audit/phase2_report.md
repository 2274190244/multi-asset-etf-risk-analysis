## 时序与研究口径

- 资产：159915.SZ、510300.SS、510500.SS、511010.SS、518880.SS。
- 数据复用 Phase 1 保留快照，不下载替换。725个日收益；首次估计使用2023-08-15至2024-08-27的252个观察。
- 2024-08-28收盘执行首次建仓，2024-08-29起产生策略收益；共同评价结束2026-08-12，共472个日收益。
- 执行日 t 使用截至 t−1 的最近252个收益；先由旧持仓完成 t 日收益，再收盘调仓、扣费，新目标 t+1 起生效。
- 21/63日是固定交易日间隔，不是自然月末/季末。月度方案23次执行（首次+22次调仓），季度方案8次执行（首次+7次调仓）。
- 非调仓日自然漂移，没有隐含每日恢复目标。Minimum Variance 没有额外集中度上限。
- 费用按实际买入和卖出金额各自收取，支持0/5/10/20 bps。费用从持仓财富支付，目标按扣费后财富建立。
- 首次建仓从现金开始，单边换手100%。初始费用在真实执行日登记，分配到第一笔 Net Return，避免遗漏；因此第一笔净收益包含首次费用与第一天市场收益。
- 252日年化、年有效rf=2%、同频超额收益Sharpe、零目标Sortino、95% signed-loss VaR和线性分位数积分CVaR，沿用 Phase 1。费用不会改变 Gross。
- 末日不默认清仓；本报告为持仓按市值计价终止，不是扣除退出费用后的清算价值。

公式、字段定义和精度验证见 [Methodology](../METHODOLOGY.md)。

## 剩余局限

1. 滚动时序避免代码层面的未来收益泄漏，但资产选择、事后样本选择和已查看历史的研究者偏差仍在；这不是前瞻实盘验证。
2. 仅472个评价日，分位数尾部与估计协方差都有不确定性；没有完整经济周期证据。
3. 供应商复权快照不是历史时点数据版本，尚未验证为总回报；原抓取时间未知，不能由重放时间补造。
4. 模拟收盘成交未考虑真实撮合、最小手数、停牌可交易性、成交量、滑点冲击；固定bps并非实际券商收费模型。
5. 费用没有按市场/品种区分最低佣金或税费；未计期末清仓成本。首个净收益合并首次费用和第一天持有收益，会影响净风险统计。
6. Minimum Variance 高度集中于国债；低历史波动不能替代利率、久期、流动性与估计误差分析。Inverse Volatility 也并非风险平价。
7. 固定2%无风险利率和252日年化仍是假设；21/63日不是自然月末/季末。未做参数搜索或根据结果挑选窗口。
8. Phase 1的隐含每日再平衡与Phase 2真实漂移并不相同；阶段对比是方法诊断，不是严格单因素因果实验。

Phase 2 至此停止。
