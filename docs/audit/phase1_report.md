## 修复内容与验证

- 金融指标独立于 UI，增加 Sortino、Calmar、Downside Volatility、CVaR。函数提供输入输出文档和测试。simple/log return、复利年化、首日亏损、零分母、缺失和数值溢出均有检查。
- Sharpe 将年有效无风险利率转换为 daily rf=(1+annual rf)^(1/252)-1；对日度超额收益使用均值和样本标准差，再乘 sqrt(252)。固定 2% 是假设，可配置。
- VaR=-Q(0.05)，使用 linear interpolation，不钳制为零；全正收益下负 VaR 表示该分位点仍是盈利。CVaR 是同一线性分位数曲线在最差 5% 区间的积分平均损失，与简单阈值尾部平均可能不同。
- 最小方差采用年化协方差并进一步合理缩放，解析梯度、ftol=1e-12、maxiter=1000；验证有限性、非负、总和为 1、目标不劣于等权及每个单资产，并检查一阶最优性残差。确定性协方差、伪成功结果及时间边界均有回归测试。
- 训练期最优年方差为 0.0002436604，低于等权 0.0253846049 和最优单资产 0.0002921377；优化执行 13 次迭代，一阶残差约 3.26e-8。这是训练期的数值正确性检查，不是未来绩效保证。
- Data Quality Report 包含每个 ticker 的首末日期、观察数、缺失数、重复数、覆盖率、异常收益和删除行数；逐行事件记录受影响资产、原因与动作。不静默 dropna，不跨缺口计算伪单日收益。
- 根据交易日历区分非交易日、源缺失未核实、不同市场日历；有证据才标停牌或无成交。当前五只 ETF 的 726 个价格日期与所用中国交易日历完全一致。异常收益是审查标志，不自动删除。无可用完整区间时仍保存质量报告及原始证据。
- 持久化 source、price_basis、retrieval timestamp、requested start/end，并保存原始响应和哈希。历史抓取时间无法恢复，明确记录 unknown_legacy_snapshot；重放时间不冒充抓取时间。
- UI 使用新数据契约，区分全样本资产描述与评价期组合表现。SQL 不再把跨缺失月份的变化当成单月收益。

完整定义见 [Methodology](../METHODOLOGY.md)。

## 仍存在的研究局限

1. 单次历史切分建立了时间边界，但评价期在本次审计中已经可见，不是预注册、完全未触碰的测试集；没有滚动稳健性证据。
2. 评价只有 218 个日收益，95% 尾部信息有限，VaR/CVaR 与年化指标有估计不确定性。
3. 最小方差高度集中于国债 ETF，未增加资产上限、收益目标或交易约束；低方差不意味着适合所有配置需求。
4. 固定权重收益代表每日恢复权重，未计交易费用、价差、流动性约束和税费。
5. 使用供应商复权价格，尚未验证其等同于可投资总回报；原始抓取时间及历史请求参数无法事后完整证明。重放请求区间单独披露。
6. 股票、黄金、债券 ETF 的选取存在研究者选择偏差；缺失原因不能从价格表可靠反推。最长完整区间选择本身是事后规则，已明确披露。
7. 固定无风险利率、252 日年化、平方根时间缩放等是研究约定。SQL 月度结果以最后可用观察为准，不能自动视为已认证的官方月末价格。

Phase 1 至此停止，未扩展后续研究功能。
