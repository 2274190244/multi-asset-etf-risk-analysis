# Phase 4 — Index Construction 完成报告

已完成固定五只ETF的等权、逆波动率规则指数，各支持自然月末和季末调仓。采用统一前复权市场价格，未混入NAV。本阶段未进入Regime、机器学习或Streamlit改造。所有结果是本样本的规则比较，不是未来收益预测。

## 6. 不同规则的研究解释

等权在调仓时给三个股票ETF合计60%配置，并给黄金、国债各20%；不等于五份独立风险，也不等于风险平价。它在本样本承担更高股票风险，取得较高收益和较深回撤。

逆波动率利用各资产自身过去波动，不使用相关矩阵；国债历史价格波动较低，因而取得主要权重。这是跨资产规则产生的资产配置效果，不是股票低波选股因子的检验，也不保证真正的组合最小波动。

月度调仓更频繁地修正漂移和更新估计，但收益方向取决于后续资产路径。当前结果没有进行费用、风险因子或市场阶段归因，不能把差异直接归因于某个单独机制或宣称alpha。

## 9. 剩余局限

1. 固定五只当前可见ETF，存在事后选池/幸存者偏差；不代表历史全市场指数。
2. 前复权市场价格的总收益等价性未完全验证，历史修订/复权重算没有时点版本库；时间隔离算法通过测试，不等于底层历史数据绝对无前视。
3. available_at为明确假设，实际发布时刻未核验；RF为固定2%假设。
4. 收盘目标瞬时执行是研究约定，未模拟冲击、滑点、申赎、整手约束和交易成本。基金费用不重复扣除。
5. 451个评价收益日不足以证明长期规则优势；252日年化不是日历年CAGR。
6. 逆波动率会集中于国债，未考虑底层相关性、久期或利率风险暴露，也不是最小方差优化。
7. 市值指数缺少数据，未实现；本阶段也不处理退市全损、强制清算或复杂成分公司行为。
8. 当持有资产无法估值时研究路径显式停止；不通过估值填充维持表面连续性。

本阶段完成并停止；不进入Regime、机器学习或UI改造。
