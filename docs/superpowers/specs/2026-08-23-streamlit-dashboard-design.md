# 中文 Streamlit 招聘展示看板设计

## 目标

为 `multi-asset-etf-risk-analysis` 项目增加一个可公开部署的中文 Streamlit 看板。招聘者打开链接后无需安装 Python、无需调用实时行情接口，即可查看五只 ETF 的市场表现、风险指标、资产相关性、组合表现、组合权重和数据质量。

看板只读取 `output_verified/powerbi/` 中已经验证的 CSV 文件，所有页面数字必须能追溯到该目录及 `output_verified/resume_facts.json`。

## 受众与定位

- 主要受众：券商、基金、银行、互联网金融的数据分析与风险管理招聘人员。
- 页面语言：中文，保留 ETF、VaR、SQL、Power BI 等常用专业缩写。
- 使用场景：招聘者在桌面或手机浏览器中进行 30 秒至 3 分钟的快速浏览。
- 视觉定位：安静、专业、偏金融分析工具，不采用营销落地页、装饰性渐变或大面积卡片堆叠。

## 方案选择

采用“预计算数据驱动的招聘展示型看板”。不在网页中重新请求 Eastmoney 或 Yahoo，也不重新运行优化器。

选择该方案的原因：

- 首屏加载稳定，不受第三方行情接口限流影响。
- 展示结果与简历中的 3,630 条记录、5 只 ETF、5 项收益与风险指标和 2 个组合保持一致。
- Streamlit Community Cloud 部署时无需配置密钥。
- 招聘者可以把注意力放在分析逻辑和结果，而不是等待数据下载。

## 文件结构

新增或更新以下文件：

```text
streamlit_app.py
requirements.txt
src/portfolio_analysis/dashboard_data.py
tests/test_dashboard_data.py
tests/test_streamlit_app.py
README.md
```

`streamlit_app.py` 只负责页面布局、控件和图表渲染。`dashboard_data.py` 负责读取、校验和转换数据，使核心逻辑可以脱离 Streamlit 单独测试。

## 数据输入

看板使用以下文件：

```text
output_verified/powerbi/prices.csv
output_verified/powerbi/asset_metrics.csv
output_verified/powerbi/portfolio_timeseries.csv
output_verified/powerbi/portfolio_metrics.csv
output_verified/powerbi/correlation_matrix.csv
output_verified/powerbi/portfolio_weights.csv
output_verified/powerbi/data_quality.csv
output_verified/resume_facts.json
```

数据模块需要验证文件存在、必需字段完整、日期可解析、数值字段有限且非空。资产累计收益由每只 ETF 在所选日期区间内的收盘价归一化计算；组合回撤由 `1 + cumulative_return` 相对历史峰值计算。看板不得修改验证数据。

## 页面结构

### 顶部概览

- 标题：多资产 ETF 收益与风险分析平台。
- 副信息：数据区间、数据来源和“个人项目｜AI Agent 辅助开发”。
- 四个紧凑指标：价格记录数、ETF 数量、收益与风险指标数、投资组合数。
- 不使用占满首屏的 Hero；首屏应同时露出第一个分析图表。

### 侧边栏

- ETF 多选，默认选择全部资产。
- 日期范围选择，默认使用完整验证区间。
- 简短方法说明：年化收益率、年化波动率、夏普比率、最大回撤和 95% 历史 VaR。
- 所有筛选只作用于适合按日期或资产过滤的图表，不改变已验证的全区间指标表口径。

### 市场表现

- 所选 ETF 的区间累计收益曲线，起点统一为 0%。
- 年化收益率与年化波动率散点图，点标签显示 ETF 名称。
- 资产指标明细表，百分比和比率采用适合阅读的格式。

### 风险分析

- 最大回撤、历史 VaR 和夏普比率对比图。
- 资产相关性热力图，横纵轴使用 ETF 中文名称。
- 对 VaR 正负口径和相关性计算窗口给出简短说明。

### 组合分析

- 等权组合与最低波动组合累计收益曲线。
- 两个组合的回撤曲线。
- 分组组合权重柱状图。
- 组合收益与风险指标对比表。

如果验证数据中的两个组合结果相同，看板如实展示，不为了视觉差异修改结果。

### 数据质量

- 输入行数、输出行数、重复值、无效价格、缺失收盘价和共同窗口记录数。
- 实际数据覆盖区间和共同收益窗口区间。
- 数据来源、完整案例同步和历史分析局限说明。

## 视觉系统

- 页面使用 Streamlit 宽屏布局，但内容宽度保持适合扫描。
- 背景为白色，正文为近黑色，主要标题使用深蓝色 `#1F4E79`。
- 图表辅助色使用青绿色 `#168C8C`、橙色 `#D97706`、中性灰和有限的蓝色，不使用渐变。
- 标题与控件尺寸克制；指标组件尺寸稳定，长文本必须换行且不得覆盖相邻内容。
- 图表采用 Plotly，开启响应式宽度、清晰悬停提示和统一中文标签。
- 不使用图标代替关键文字，不使用无意义的装饰图形。

## 错误处理

- 缺少文件时，页面显示缺少的相对路径并停止渲染。
- 字段不完整时，显示文件名和缺少字段，不继续计算图表。
- 日期筛选后没有数据时，给出调整筛选范围的提示，不显示空坐标轴。
- 非有限指标或无法解析日期时，数据模块抛出明确异常，界面转换为用户可理解的错误信息。
- 页面不得自动回退到合成数据或旧的 `output/` 目录。

## 性能与部署

- 使用 `st.cache_data` 缓存只读 CSV 加载。
- 所有文件路径相对于仓库根目录解析，避免本机绝对路径。
- `requirements.txt` 固定最低必要依赖：Streamlit、pandas、NumPy、Plotly、SciPy 和 requests。
- Streamlit Community Cloud 入口为仓库根目录的 `streamlit_app.py`，分支为 `main`。
- 不使用环境变量、API 密钥或数据库服务。

## 测试与验证

### 自动化测试

- 验证八个输入文件均可加载并具有必需字段。
- 验证资产区间累计收益从 0 开始，且筛选资产和日期后行数正确。
- 验证组合回撤不大于 0，并与累计财富的历史峰值关系一致。
- 验证相关性矩阵为方阵、对称且对角线为 1。
- 验证缺失文件、缺失字段和空筛选产生明确错误。
- 使用 Streamlit 的应用测试能力做页面烟雾测试，确认四个标签页、标题和关键数字存在且无未捕获异常。
- 保持原有 88 项项目测试通过。

### 视觉验证

- 本地启动 Streamlit 服务器。
- 在桌面和手机宽度检查首屏、侧边栏、标签页和全部图表。
- 检查图表非空、照片或装饰资源不存在、文本不重叠、表格不越界、中文字符正常。
- 保存一张桌面截图用于 GitHub README，截图只展示看板，不包含本机路径或账号信息。

## 非目标

- 不实现实时行情、自动交易、登录系统或云数据库。
- 不在网页中重新训练模型或重新运行最低波动优化。
- 不新增未经验证的投资收益、业务提升或预测结论。
- 不生成或伪装 Power BI PBIX 文件。

- 新增测试和原有测试全部通过。
